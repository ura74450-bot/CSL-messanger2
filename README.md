# Мессенджер

Чаты в реальном времени, голосовые, фото, аудиозвонки (WebRTC), поиск по нику, аватар, несколько аккаунтов.

## Запуск локально
    npm install
    npm start        # http://localhost:3000

## Деплой на Render
1. Залей все файлы в репозиторий GitHub.
2. Render → New → Web Service → выбери репозиторий.
3. Build Command: `npm install`, Start Command: `npm start` (или просто используй render.yaml).
4. Нажми Deploy. Готово — сайт работает по HTTPS (нужен для микрофона).

## Важно
- Данные хранятся в папке `data/`. На бесплатном Render диск сбрасывается при перезапуске.
  Для постоянного хранения подключи Render Disk (платно) и задай переменную `DATA_DIR` = путь диска.
- Звонки используют STUN. В сложных сетях (мобильный интернет, строгие NAT) нужен TURN-сервер:
  добавь его в массив `ICE` в `public/index.html`.
